# Universal Language Documentation & API Reference

Utiliza esta skill cuando el desarrollador Brayan (`bscl`) o el asistente requiera consultar especificaciones oficiales, sintaxis idiomática o APIs de cualquier lenguaje.

## 📚 Fuentes de Documentación por Lenguaje

### 1. Java & Android
* **Java SE:** [Oracle Java Docs](https://docs.oracle.com/en/java/) (Java 17 / 21 LTS).
* **Android:** [Android Developers](https://developer.android.com/reference) (AccessibilityService, KeyEvents, WindowManager).

### 2. Python
* **Python 3:** [Python Official Docs](https://docs.python.org/3/) y [Real Python](https://realpython.com/).
* **Tipado:** Módulo `typing`, `dataclasses`, `pydantic`.

### 3. JavaScript & TypeScript
* **JavaScript / Web APIs:** [MDN Web Docs](https://developer.mozilla.org/).
* **TypeScript:** [TypeScript Handbook](https://www.typescriptlang.org/docs/).

### 4. PHP & Laravel
* **PHP:** [PHP.net Manual](https://www.php.net/manual/es/).
* **Laravel:** [Laravel Official Docs](https://laravel.com/docs/).

### 5. Bases de Datos & SQL
* **PostgreSQL:** [PostgreSQL Documentation](https://www.postgresql.org/docs/).
* **MySQL:** [MySQL Reference Manual](https://dev.mysql.com/doc/).
* **SQLite:** [SQLite Documentation](https://www.sqlite.org/docs.html).

### 6. Rust & Go
* **Rust:** [The Rust Book](https://doc.rust-lang.org/book/) y [Rust by Example](https://doc.rust-lang.org/rust-by-example/).
* **Go:** [Go Documentation](https://go.dev/doc/).

---

## ⚡ Directrices de Respuesta Técnica
1. **Código Idiomático:** Proporcionar siempre la forma canónica moderna del lenguaje, evitando modismos antiguos o deprecados.
2. **Tipado Estricto:** Privilegiar tipos estáticos y validación de esquemas donde esté disponible.
3. **Manejo Seguro de Errores:** Incluir siempre control de excepciones, `try/catch` o patrones de tipo `Result`/`Optional`.
