# ⚙️ Personalización y Extensión de Antigravity

- **Tipo:** Habilidades del Sistema Antigravity
- **Relacionado:** [[Catalogo de Skills (Antigravity)]], [[Colaboracion con IA (Antigravity)]]

---

## 🛠️ Habilidades Incluidas

### 1. `antigravity-guide`
* Dominio completo del ecosistema Antigravity: CLI `agy`, herramientas del IDE, atajos de teclado y comandos de chat (`/goal`, `/schedule`, `/grill-me`, `/learn`).

### 2. `agy-customizations`
Permite crear **tus propias habilidades y reglas personalizadas** para que yo aprenda flujos de trabajo únicos de tus proyectos:
* **Crear Skills:** Añadir carpetas en `.agents/skills/<nombre_skill>/SKILL.md` con instrucciones paso a paso.
* **Crear Rules:** Archivos `GEMINI.md` o reglas en `.agents/rules/` con normas de estilo o arquitectura que siempre debo respetar.
* **Conectar Servidores MCP:** Integrar nuevas herramientas y APIs externas.

---

## 💡 Ejemplos de uso:
* *"Crea una nueva Skill personalizada llamada `android-tv-build` que contenga todos los pasos para compilar y probar en la TV Box."*
* *"Añade una regla para que todo el código Java siempre use nombres de variables en camelCase estricto."*
