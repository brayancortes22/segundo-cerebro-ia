# ☁️ Suite de Desarrollo Firebase

- **Tipo:** Plugin Skills Oficiales (`firebase`)
- **Relacionado:** [[Catalogo de Skills (Antigravity)]], [[00_Centro_de_Mando]]

---

## 🛠️ Componentes y Skills Disponibles

| Skill | Función Principal |
| :--- | :--- |
| `firebase-firestore` | Base de datos NoSQL con sincronización en tiempo real y listeners offline. |
| `firebase-auth-basics` | Sistema de login (Google, Email/Contraseña, Teléfono, Anónimo). |
| `firebase-data-connect` | Backend relacional con PostgreSQL y GraphQL gestionado desde Firebase. |
| `firebase-ai-logic-basics` | Ejecución de lógica de IA (Gemini) segura desde el cliente con Firebase App Check. |
| `firebase-app-hosting-basics` | Despliegue optimizado para aplicaciones modernas (Next.js, Angular). |
| `firebase-hosting-basics` | Alojamiento CDN ultrarrápido para sitios web estáticos o SPAs. |
| `firebase-security-rules-auditor` | Análisis estático y auditoría estricta de vulnerabilidades en `firestore.rules`. |
| `firebase-crashlytics` | Detección automática de crasheos y reportes de errores en Android e iOS. |
| `firebase-remote-config-basics` | Modificación de variables y feature flags sin lanzar una nueva versión de la app. |
