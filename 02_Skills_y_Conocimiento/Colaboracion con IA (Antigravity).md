# 🤖 Colaboración con IA (Antigravity)

- **Propósito:** Optimizar nuestra dinámica de trabajo y comunicación entre tú y yo.
- **Relacionado:** [[00_Centro_de_Mando]]

---

## ⚡ Cómo sacarle el 100% de provecho a esta integración

### 1. El ciclo Obsidian + Antigravity
1. **Tú anotas ideas o requerimientos:** En cualquier nota de tu bóveda Obsidian (por ejemplo, agregas un checkbox `[ ] Quiero agregar un botón para X en Accesorios Lilis`).
2. **Me das la instrucción:** *"Revisa la nota de Accesorios Lilis e implementa el botón que anoté"*.
3. **Yo ejecuto y actualizo:** Modifico el código fuente, compilo o pruebo, y marco la tarea como completada `[x]` en la nota de Obsidian automáticamente.

---

## 🛠️ Comandos y Habilidades que Domino
* **Automatización y Shell:** PowerShell, scripts batch (`.bat`), Git y compilaciones.
* **Desarrollo Web & Mobile:** Java (Android nativo), Python, JavaScript, CSS moderno.
* **Diagramación:** Diagramas Mermaid integrados que se renderizan directamente en tus notas de Obsidian.
* **Gestión de Memoria:** Creación de bitácoras de errores resueltos para no tropezar dos veces con la misma piedra.
