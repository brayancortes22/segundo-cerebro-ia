# 🌐 Frontend Moderno & Extensiones de Chrome

- **Tipo:** Plugin Skills (`modern-web-guidance-plugin`)
- **Relacionado:** [[Catalogo de Skills (Antigravity)]], [[00_Centro_de_Mando]], [[Diseno Responsivo y Adaptabilidad (Web, Mobile y TV)]]

---

## 🎨 Habilidades Incluidas

### 1. `modern-web-guidance`
Asegura que cualquier desarrollo web cumpla con los estándares más actuales y fluidos:
* **Layouts y UI:** Popovers nativos, diálogos modales HTML5 (`<dialog>`), efectos de glassmorphism con `backdrop-filter`, `container queries`, y selector relacional `:has()`.
* **Animaciones:** Animaciones dirigidas por scroll (*Scroll-driven animations*), View Transitions API sin frameworks pesados.
* **Rendimiento:** Métricas Core Web Vitals (LCP, INP), `content-visibility`, optimización de fuentes y carga diferida.

### 2. `chrome-extensions`
Construcción y empaquetado de extensiones para Google Chrome según la especificación **Manifest V3**:
* Service Workers de fondo.
* Inyección de Content Scripts en páginas específicas.
* Paneles laterales (*Side Panel*), menús contextuales y popups interactivos.
* Preparación para publicación y verificación en Chrome Web Store.
