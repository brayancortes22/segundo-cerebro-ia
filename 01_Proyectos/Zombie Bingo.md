## ⚡ Descripción y Arquitectura

Juego multijugador temático de bingo táctico en ambientación post-apocalíptica de zombis. Diseñado con una arquitectura desacoplada:

1. **Frontend SPA:**
   - Construido con React 19, tipado estricto en TypeScript y estilos con Tailwind CSS v4.
   - Efectos visuales interactivos y ambientación 3D con Three.js.
   - Despliegue continuo estático en GitHub Pages y Vercel.
2. **Backend API Contenerizado:**
   - API REST en PHP 8.2 con Apache y PDO MySQL estructurado para alta concurrencia.
   - Contenerizado con Docker multi-etapa y manifiesto `render.yaml` para despliegue automatizado en la nube de Render.
